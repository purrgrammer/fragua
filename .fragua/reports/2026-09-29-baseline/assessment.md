# Assessment

fragua is a durable AI-workflow execution engine — YAML workflows compiled to a deterministic state machine, run through pluggable LLM backends, recorded as a replayable event log over a single SQLite store. **Verdict: architecturally sound and unusually well-tested, but the security perimeter (unauthenticated local API + a porous tool sandbox) and a handful of invariant leaks (swallowed OCC on terminal fast-paths, a shared-thread scan that inherits stale routing, in-transaction serialization) are the real exposure — the design's promises hold in the core and fray at the edges.** Baseline: **CI green** — typecheck (10 packages), biome (857 files), test:node (3583 pass / 1 skip), test:web (725 pass) all exit 0.

## Do now

1. **Browser CSRF on the unauthenticated local API** — *verified, HIGH.* No CORS/Origin/Content-Type gate anywhere in `packages/server` (grep: 0 matches); `readJson()` in `routes.ts` (~773), `schedule-routes.ts` (~178), `providers.ts` uses `c.req.json()` with no content-type check, so any visited web page can POST a `text/plain` simple request (no preflight) that drives `POST /workflows`, `POST /runs`, `POST /runs/:id/accept` (git merge into the operator's tree, ~617), and `POST /providers/:name/credentials` (API-key write, providers.ts ~168). Loopback bind does not help — the browser sends the request. **Fix:** reject requests whose `Origin`/`Sec-Fetch-Site` is cross-site and require `Content-Type: application/json` on every state-changing route.

2. **Shared-thread scans inherit an upstream node's stale route/output** — *inferred, HIGH.* `backend.ts:648` computes `hydratedCount` and the comment at 638–643 says every self-abort/route/emit scan is sliced after it, but only `findAbortToolCall` is sliced (808/933/986); `findRouteToolCall` (993) and `findEmitOutputCall` (807, 1005) scan `agent.state.messages` in full. A downstream node that fails to emit its own `route`/`emit_output` can silently adopt the previous node's tool call, and the full-transcript emit check at 807 suppresses the corrective re-prompt. **Fix:** slice all three scans by `hydratedCount` exactly as the abort scan does, and add a test where an upstream emit precedes a silent downstream node.

3. **OCC-append results swallowed on ~7 terminal/pause fast-paths in `dispatchOne`** — *verified, medium.* Seven fast-paths in `executor.ts` (`engine_incompatible` ~536, unparseable ~559, `worktree_error` ~706, `max_loops` ~888, leaked-timeout ~1114, reactive-budget halt/pause ~1176, abort-loop ceiling ~1200) call `await tryAppendFact(...)` then `return { kind:'terminal' }` without checking the boolean; the cancel (~597) and pause (~662) arms route conflicts through `onOccConflict`, and the cancel comment names the exact failure ("a swallowed conflict… a running zombie"). **Fix:** route every unchecked fast-path's OCC result through `onOccConflict`, leaving the run `running` for retry rather than falsely terminal.

4. **`JSON.stringify` runs inside the write transaction (I1 breach), invisible to the lint** — *verified, medium.* `appendObservabilityEvents` (store.ts ~704) and `appendMessage` (~1048) call `this.validatePayload(...)` inside `this.writeTxn(...)`, and `validatePayload` (~2463) does `JSON.stringify`; the I1 lint greps writeTxn bodies for the literal `JSON.stringify(`, so the helper indirection hides both breaches (`appendFact`/`appendIntent`/`appendDaemonEvent` correctly serialize before the txn). **Fix:** hoist the `validatePayload` calls above `writeTxn` in both methods, and make the lint follow one-hop helper calls (or ban I/O-shaped helpers by name) so the breach class is caught.

5. **Porous tool sandbox: bash/read escape the worktree, run inputs skip the injection wrap** — *verified (bash/read) + inferred (TOCTOU), medium.* `local-env.ts:44` deliberately does no absolute-path gating, so bash reads `/etc/passwd`, `curl`s arbitrary hosts, and writes via absolute paths; the read tool reads bytes via direct `node:fs` (`tools.ts:665`), bypassing the `ExecutionEnvironment` and relying on a separate `env.exists` side-gate (TOCTOU); and `substitution.ts` wraps only `${{ outputs }}` in content-derived delimiters (`handler-bridge.ts:88` `wrapOutputs:true`) while `${{ inputs.x }}` lands verbatim in the llm prompt (core-F3). **Fix:** confine bash/read to the worktree (cwd-relative resolution + a realpath re-check at open time), and apply the same injection-delimiter wrap to interpolated run inputs.

## Patterns

- **Discipline enforced by convention, not by a lint that can't be evaded.** The invariants are real but the guards are regex/directory scans with holes: the I1 lint omits `fetch` and is blind to `JSON.stringify` inside helpers (store#1/#8); the sub-interface lint matches only the literal `IEventStore` and is defeated by a type alias (store#8); no lint enforces SQL-placement, so `retainPortableTables`/`vacuum` carry inline SQL in `store.ts` (store#3); browser-safety and handler-discipline scan by directory + regex, not the import graph, and the raw-fetch heuristic lets `globalThis.fetch(` through with no `no-restricted-imports` backstop (core-F2); the routing-accessor lint appears absent (core-F5); `setRunTitle` writes and seven direct store reads bypass the intent/read planes with no discipline test (surface-F2/F3).
- **God files with oversized closures.** `store.ts` 2577 (~95-method class, store#5), `executor.ts` 2280 with a ~1700-line `runOne` and 600–770-line `dispatchOne`/`runFanout` closures over shared mutable state (daemon-F3), `backend.ts` 1553 mixing provider transport with orchestration and a ~700-line `runInner` (agent-F5), `validator.ts` 1774.
- **Replay/live divergence.** Two independent places where derived state can disagree with live state: the read plane's `existsSync` in run-detail projection (core-F1) and the reducer-vs-sweep split on `current_node` for `fact.run_requeued_after_crash` (store#2). Both undercut the "events are truth, replay is faithful" promise.
- **Decision/effect boundary not universal.** The linear path's `planTransition`/`planAbort` are pure, but fan-out fact-selection lives inline in `runFanout` (daemon-F2), the OCC fast-paths inline their own commit handling (daemon-F1), and HandlerContext wiring is duplicated between the linear and branch dispatch sites (daemon-F6, already drifted once).

## What held up

The load-bearing invariants are real. **Store:** OCC-checked facts vs always-appendable intents as two distinct methods (A3); O(1) per-run seq via `UPDATE … RETURNING` (A5); 8KB routing / 4KB payload / 1MiB message caps with byte pre-check + SQL CHECK backstop, observability truncated not rejected (A6/A7/A9); enum-consumer lints (A13). **Daemon:** pure `planTransition`/`planAbort` (B1); `runOne` re-reads state and returns on terminal/paused (B2); contract-version gate pauses out-of-window pins (B3); cancel-wins intent fold (B4); ## Critical path

1. **Close the API's front door (CSRF + content-type gate).** The unauthenticated local API is the amplifier for every downstream write — until forged cross-site requests are rejected, hardening the sandbox or the planes behind it protects nothing. Gates step 4's sandbox work.
2. **Stop the executor stranding runs (swallowed OCC fast-paths).** Runs must reliably reach a terminal or retryable state before any replay/observability work can be trusted; a run falsely marked terminal (or silently left `running`) poisons everything downstream.
3. **Restore store invariant + replay integrity (in-txn serialization, reducer/sweep divergence).** The store is the single coordination surface; replay must equal live state before the read-plane and import paths can be trusted. Gates step 4's read/routing fixes.
4. **Fix read/routing correctness (read-plane FS I/O, shared-thread scan, input injection wrap).** These depend on a faithful store fold (step 3) and a closed perimeter (step 1); they make projections deterministic and routing decisions honest.
5. **Harden the discipline lints and reconcile the docs.** With the specific violations fixed in 1–4, upgrade the lints to AST/import-graph so the fixes can't regress, then align SPEC/ARCHITECTURE/README/reference to the now-correct code.
